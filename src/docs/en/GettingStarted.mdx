# Getting Started

React components styled with Tailwind CSS and built on
[Radix UI](https://www.radix-ui.com/primitives) primitives, so keyboard
navigation, focus management and ARIA come built in.

## Requirements

- React 19
- Tailwind CSS 4.1 or later, set up in your app (for example with
  `@tailwindcss/vite`)

## Install

The package is private on GitHub Packages. To install it, ask the maintainer
for read access to the package, then create a GitHub personal access token
(classic) with the `read:packages` scope and add an `.npmrc` next to your app's
`package.json`:

```ini
@noactionjaxn:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

Set `GITHUB_TOKEN` in your shell, CI and hosting provider rather than writing
the token into the file.

```sh
npm install @noactionjaxn/another-react-tailwind-component-library
```

React, React DOM and Tailwind are peer dependencies: the library uses the
versions your app already has.

### Optional dependencies

Accolades, Sponsors and Carousel use [Embla Carousel](https://www.embla-carousel.com/).
It's an optional peer dependency, so install it only if you use one of them,
and import them from their own entry points. The main entry never loads Embla.

```sh
npm install embla-carousel-react embla-carousel-autoplay
```

```tsx
import {
  Accolades,
  AccoladesItem,
} from "@noactionjaxn/another-react-tailwind-component-library/accolades";
import {
  Carousel,
  CarouselSlide,
} from "@noactionjaxn/another-react-tailwind-component-library/carousel";
import {
  Sponsors,
  SponsorsLogo,
} from "@noactionjaxn/another-react-tailwind-component-library/sponsors";
```

PhoneInput uses [libphonenumber-js](https://gitlab.com/catamphetamine/libphonenumber-js)
to format numbers as they're typed. It's optional in the same way:

```sh
npm install libphonenumber-js
```

```tsx
import { PhoneInput } from "@noactionjaxn/another-react-tailwind-component-library/phone-input";
```

## Add the CSS

The library's stylesheet includes Tailwind itself, so it replaces
`@import "tailwindcss"` in your main CSS file. It also tells Tailwind to scan the
library's components for the classes they use, so no `@source` line is needed.

```css
@import "@noactionjaxn/another-react-tailwind-component-library/styles.css";

/* Your own styles and theme overrides go after it. */
```

Keep the import on the first line. It loads the Roboto fonts from Google Fonts,
and browsers ignore a font `@import` that comes after other rules.

## Use a component

```tsx
import {
  Button,
  Label,
  TextInput,
} from "@noactionjaxn/another-react-tailwind-component-library";

export function SignUp() {
  return (
    <form className="flex items-end gap-2">
      <div className="flex flex-col gap-2">
        <Label htmlFor="email">Email</Label>
        <TextInput id="email" type="email" placeholder="you@example.com" />
      </div>
      <Button type="submit">Sign up</Button>
    </form>
  );
}
```

Most components take the same three styling props:

- `variant`: the style, from `solid`, `soft`, `outline` and `ghost`. Each
  component supports the ones that make sense for it.
- `size`: `sm`, `md` (the default) or `lg`. Form controls and buttons of the
  same size line up in a row.
- `colorScheme`: the color palette to use. See [Theming](?path=/docs/theming--docs).

`className` and `style` are passed through last, so they can override anything.
Components built on Radix take that primitive's props too; each component page
lists them.

## Providers

Two components need a provider placed once, near the root of your app:

```tsx
import {
  ToastProvider,
  ToastViewport,
  TooltipProvider,
} from "@noactionjaxn/another-react-tailwind-component-library";

export function App() {
  return (
    <TooltipProvider>
      <ToastProvider>
        {/* your app */}
        <ToastViewport />
      </ToastProvider>
    </TooltipProvider>
  );
}
```

## Fonts

Tailwind's `font-sans`, `font-serif` and `font-mono` use Roboto, Roboto Serif
and Roboto Mono. Use them in your own markup as usual, or redefine
`--font-sans` and the others in `@theme` to change the fonts everywhere.
